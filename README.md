#  PIT WALL – GP São Paulo

##  Sobre o Projeto

O **PITWALL – GP São Paulo** é um projeto desenvolvido utilizando HTML5 e CSS3, com o tema de Fórmula 1 e o Grande Prêmio de São Paulo, realizado no Autódromo de Interlagos.

O objetivo é criar uma página que apresente informações sobre a corrida, os pilotos, a classificação e os ingressos, utilizando um visual moderno inspirado no universo da Fórmula 1.

##  Funcionalidades

O site possui as seguintes seções:

- **Início:** apresentação do GP de São Paulo, com informações sobre a corrida, número de voltas, distância por volta e quantidade de curvas.
- **Pilotos:** cards com os nomes, números e equipes dos pilotos.
- **Classificação:** tabela com posições, pilotos, equipes, vitórias, diferenças e pontuação.
- **Ingressos:** apresentação dos setores disponíveis e seus respectivos preços.
- **Formulário:** campos para preencher nome, e-mail, setor, dia, quantidade de ingressos, perfil, foto e recado para o piloto.

##  Tecnologias Utilizadas

- **HTML5:** estruturação do conteúdo da página.
- **CSS3:** estilização, cores, organização dos elementos e responsividade.
- **Google Fonts:** utilização das fontes Titillium Web e Source Code Pro.

##  Identidade Visual

O projeto utiliza um tema inspirado nas pistas de Fórmula 1, com as seguintes cores principais:

- 🔴 Vermelho: `#ed0808`
- ⚫ Preto: `#0b0b0e`
- Cinza: `#17171f`
- Branco: `#f5f5f7`

O layout utiliza um estilo esportivo, com destaque para os títulos, botões, tabelas e informações dos pilotos.

##  Responsividade

O site possui adaptações para dispositivos menores, como celulares e tablets, utilizando Media Queries no CSS para reorganizar os elementos e facilitar a navegação.

##  Como Executar o Projeto

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Verifique se a imagem `formula1.jpg` está dentro da pasta `assets`.
4. Abra o arquivo `index.html` no navegador.
5. Navegue pelas seções do site utilizando o menu principal.
